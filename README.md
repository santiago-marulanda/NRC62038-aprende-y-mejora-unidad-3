# Principios de Desarrollo de Software - Solución Aprende y Mejora Unidad 3

Este proyecto corresponde a la solución de la actividad **Aprende y Mejora - Unidad 3** de la asignatura **Principios de Desarrollo de Software**.

La propuesta se basa en la empresa ficticia **7 Torques**, trabajada previamente en unidades anteriores del curso. Para esta entrega, se desarrolló una **landing page** orientada a un taller de mantenimiento y reparación de motocicletas, con el objetivo de construir un proyecto simple que permitiera aplicar de forma práctica el uso de **Git** y **GitHub** en un entorno colaborativo.

El diseño base de la interfaz fue generado con **Stitch de Google**, herramienta que permitió obtener una estructura inicial en HTML y CSS. A partir de ello, el equipo centró su trabajo en el uso de herramientas de control de versiones y colaboración, cumpliendo con los requerimientos de la actividad, como la creación de commits, ramas, fusiones y trabajo compartido en un repositorio público.

## Objetivo del proyecto

Desarrollar y publicar una landing page estática para la empresa ficticia **7 Torques**, utilizando un flujo de trabajo colaborativo con **Git** y **GitHub**, con el fin de fortalecer el aprendizaje de:

- creación y gestión de repositorios,

- uso de commits y control de versiones,

- trabajo con ramas,

- fusión de cambios y resolución de conflictos,

- colaboración entre integrantes del equipo,

- documentación básica del proyecto.

## Instalación en ambiente local

Sigue estos pasos para ejecutar el proyecto localmente:

1. Instala Git desde el sitio oficial: https://git-scm.com/

2. Clona este repositorio:
   ```bash

   git clone https://github.com/santiago-marulanda/NRC62038-aprende-y-mejora-unidad-3.git
   ```
3. Ingresa al directorio del proyecto: 
   ```bash

   git clone https://github.com/santiago-marulanda/NRC62038-aprende-y-mejora-unidad-3.git
   ```
4. Abre el archivo index.html en tu navegador o en tu editor de código para visualizar la interfaz.
